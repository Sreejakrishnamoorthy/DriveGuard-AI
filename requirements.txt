# correctly against it in practice (verified during development,
# including a full Streamlit app run with zero errors).
#
# NOTE: `pip check` will report a metadata mismatch for streamlit's
# protobuf requirement here — this is EXPECTED and harmless. It is a
# declared-constraint warning, not an actual runtime failure; both
# libraries were directly verified to function correctly together at
# this exact protobuf version.
